A pane is one terminal: a shell or a command with its own pseudo-terminal. The
runtime owns every pane and its process, so a pane keeps running when you
close the window. Each tab starts with one pane, and you split it to add more.
A tab holds at most 64 panes.

## Split a pane

| Keys | Action |
| --- | --- |
| `ctrl+b` `%` | Split the focused pane into left and right |
| `ctrl+b` `"` | Split the focused pane into top and bottom |

The new pane opens in the focused pane's current directory and takes the
focus. It runs your shell, or the command you passed to `telar` when you
opened the window. If the focused pane has no room left to split, nothing
happens.

You can also split with the mouse. When it is wide enough, the focused pane,
and any pane under the pointer, shows four buttons at the right of its
header: **Split right**, **Split below**, **Expand pane** and **Close pane**.

## Move between panes

| Keys | Action |
| --- | --- |
| `ctrl+b` `left` | Focus the pane to the left |
| `ctrl+b` `right` | Focus the pane to the right |
| `ctrl+b` `up` | Focus the pane above |
| `ctrl+b` `down` | Focus the pane below |

Clicking a pane, its header or its border also focuses it. The focused pane
has an accent border; the others are dimmed. When there is no pane in that
direction, focus stays where it is.

## Resize panes

| Keys | Action |
| --- | --- |
| `ctrl+b` `shift+left` | Move the nearest split edge left |
| `ctrl+b` `shift+right` | Move the nearest split edge right |
| `ctrl+b` `shift+up` | Move the nearest split edge up |
| `ctrl+b` `shift+down` | Move the nearest split edge down |

Each press moves the focused pane's nearest split edge in that direction by
5% of the split. A split stays between 10% and 90%, and Telar refuses a
resize that would leave a pane too small to show its content. Resizing does
nothing while the tab is in fullscreen.

To resize with the mouse, drag the divider between two panes.

## Fullscreen

Press `ctrl+b` `z` to make the focused pane fill the whole tab, and again to
return to the split layout. Telar keeps the split layout and its proportions,
so the panes come back where they were. While a tab is in fullscreen, its
caption in the tab strip ends with a ⛶ mark.

A fullscreen pane shows a strip along its bottom edge with one entry per pane
in the tab and a control to leave fullscreen. Click an entry to show that
pane. With the keyboard, `ctrl+b` `left` and `ctrl+b` `right` show the
previous and next pane without wrapping around; `ctrl+b` `up` and
`ctrl+b` `down` do nothing.

## Close a pane

Press `ctrl+b` `x` to close the focused pane. Telar does not ask for
confirmation: closing a pane ends its process. The remaining panes take over
its space.

When the program in a pane exits on its own, the pane leaves the layout in the
same way.

## Scroll

| Keys | Action |
| --- | --- |
| `ctrl+b` `-` | Scroll the focused pane up |
| `ctrl+b` `=` | Scroll the focused pane down |

Each press is one wheel step. Hold the key to keep scrolling; the binding
repeats at most every 100 ms. The scroll keys and the mouse wheel follow the
program in the pane:

- When the program reports mouse events, it receives a wheel event and
  decides how far to scroll.
- When a full-screen program such as a pager enables alternate scrolling,
  it receives three cursor keys per step.
- Otherwise the pane's scrollback moves by three rows per step.

The scroll keys always act on the focused pane, never on the pane under the
pointer. Typing or pasting into a pane returns it to the live output.

## Copy mode

Press `ctrl+b` `[` to enter copy mode in the focused pane. Copy mode moves a
cursor through the pane's scrollback with the keyboard, so you can select
and copy text without the mouse. The bottom bar shows the copy-mode keys
until you leave.

| Keys | Action |
| --- | --- |
| `h` `j` `k` `l`, arrow keys | Move the cursor |
| `w` `b` `e` | Next word, previous word, end of word |
| `0`, `home` | Start of the line |
| `^` | First non-blank character |
| `$`, `end` | Last non-blank character |
| `{` `}` | Previous and next paragraph |
| `g` `G` | Top and bottom of the scrollback |
| `page_up`, `page_down`, `ctrl+b`, `ctrl+f` | Up or down one page |
| `ctrl+u` `ctrl+d` | Up or down half a page |
| `v`, `space` | Start or stop a character selection |
| `V` | Start or stop a line selection |
| `y`, `enter` | Copy the selection and leave copy mode |
| `/` `?` | Search forward or backward |
| `n` `N` | Next or previous match |
| `o` | Open the link under the cursor |
| `escape` | Clear the selection, or leave copy mode when there is none |
| `q` | Leave copy mode |

Leaving copy mode returns the pane to where it was scrolled when you entered.
In copy mode, the mouse wheel scrolls three rows per step while the pointer is
over the pane.

## Select with the mouse

Drag with the left button to select text. Double-click selects a word and
triple-click selects a line. Releasing the button copies the selection to the
clipboard.

When the program in the pane reports mouse events, the mouse goes to the
program instead. Hold `shift` while you drag to select text anyway.

| Keys | Action |
| --- | --- |
| `cmd+c` (macOS), `ctrl+shift+c` (Linux) | Copy the mouse selection |
| `cmd+v` (macOS), `ctrl+shift+v` (Linux) | Paste the clipboard into the focused pane |

On Linux, a middle click pastes the primary selection when the system
provides one.

## The pane header

Each pane in a split layout has a header above its terminal. From left to
right it shows:

- A mark for the program running in the pane. While the prefix is pending,
  the mark shows the pane's number.
- The name of the program in the foreground, or `shell` when there is none.
- The agent's session title when an agent runs in the pane, otherwise the
  pane's current directory.
- The agent's status and the progress the program reports, when there is any.

When an agent in another pane needs your input, that pane's border is
highlighted until you focus it. See [Agents](/docs/agents) for the agent
states.

## When the window closes

Closing the window does not stop your panes. Their processes keep running
in the runtime, and the next window you open connects to them again. See
[Workspaces](/docs/workspaces#detach-and-reconnect) for detaching and
reconnecting.

## Control panes from the CLI

`telar pane` reads and drives panes from a shell. Commands that change the
layout act through a window, named with `--client ID`. `telar client list`
prints the ids of the attached windows. Inside a pane, `--current` names that
pane.

| Command | What it does |
| --- | --- |
| `telar pane list` | List every pane with its workspace, tab and lifecycle |
| `telar pane get ID` | Show one pane |
| `telar pane read ID` | Print recent text from a pane |
| `telar pane search ID TEXT` | Find text in a pane's history |
| `telar pane watch ID` | Print a pane's text as JSON lines whenever it changes |
| `telar pane send-keys ID TEXT` | Type text into a pane no person has focused |
| `telar pane split ID horizontal\|vertical --client ID` | Split a pane left/right or top/bottom |
| `telar pane create --client ID` | Split the window's focused pane left/right |
| `telar pane focus ID --client ID` | Focus a pane |
| `telar pane resize ID left\|right\|up\|down --client ID` | Move a pane's nearest split edge one step |
| `telar pane fullscreen ID --client ID` | Toggle a pane fullscreen |
| `telar pane scroll ID DELTA --client ID` | Scroll a pane by a signed number of rows |
| `telar pane copy ID X1,Y1:X2,Y2 --client ID` | Copy a range of a pane's text to the window's clipboard |
| `telar pane close ID --client ID` | Close a pane |

For example:

```sh
telar client list
telar pane list
telar pane split 7 vertical --client 3
telar pane read --current --lines 100
```

`telar pane send-keys` refuses a pane that a person has focused in a window,
so it never types where you are typing. `telar client copy-mode --client ID`
enters copy mode in a window's focused pane.

### Save and restore a layout

`telar layout` exports the active tab's layout from a window as a token: the
split tree, the focused pane, the fullscreen state and the sidebar
preferences. Apply the token later to the same tab with the same panes to
restore that arrangement.

```sh
token=$(telar layout get --client 3)
telar layout apply "$token" --client 3
```

The window refuses a token for another tab or for a tab whose panes changed.

## Configuration

Every binding on this page can be changed. See
[Config](/docs/config#keybindings) for the syntax. The pane actions are
`telar.action.split_pane`, `focus_pane`, `resize_pane`, `scroll_pane`,
`toggle_pane_fullscreen`, `close_pane` and `copy_mode`.

`telar.action.navigate_pane({ direction = ... })` works like `focus_pane`,
except when the focused pane runs Neovim: then it sends `ctrl+h`, `ctrl+j`,
`ctrl+k` or `ctrl+l` to Neovim instead. An editor that reaches its own edge
can hand focus back with `telar pane focus --current --direction DIRECTION`.

`client.pane_gaps` (default `true`) leaves a one-cell gap between split
panes.

```lua
return {
  api_version = 2,
  client = {
    pane_gaps = false,
  },
}
```
