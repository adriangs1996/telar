telar machine check: Reach a machine's runtime over SSH and compare wire schemas

Usage: telar machine check LABEL [--json]

Effects: runs `telar server endpoint` on the machine, which starts its runtime when
none runs, and `telar integration status editor` there.

Results: JSON `label`, `reachable`, and when reachable `schema`, `local_schema`,
`compatible`, `home`, `shell`, `socket`, else `error`, `detail`; and `editor`, a list
of what the machine says of the Neovim of its editor panes (`present at PATH` or
`absent`, then a `needs ...` for git or a C compiler telar's own configuration lacks
there), when its telar says it. Exit 0; 1 when
unreachable or the schemas differ (run `machine setup` to install this build there).
