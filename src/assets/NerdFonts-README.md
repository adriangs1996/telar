# Nerd Fonts

This is an archived font from the Nerd Fonts release v3.5.1.

For more information see:

* https://github.com/ryanoasis/nerd-fonts/
* https://github.com/ryanoasis/nerd-fonts/releases/latest/

# Symbols Only

This font contains all symbols and is intended to be used as fallback or
together with fontconfig, so individual fonts do not need to be patched.
